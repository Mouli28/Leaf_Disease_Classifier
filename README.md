# Plant Disease Detection using Deep Learning

##  Overview

A deep learning model to detect tomato leaf diseases using image classification.

## Problem Statement

Farmers need early detection of crop diseases to prevent yield loss.

## Solution

* Used transfer learning with pre-trained CNN
* Applied data augmentation
* Trained model for disease classification

## Model Details

* Model: Transfer Learning CNN
* Accuracy: 95%

## Results

* Achieved 95% accuracy
* Improved robustness using augmented dataset

* Python
* TensorFlow
* OpenCV
